# ข้อมูลอ้างอิง (ไม่ใช่ข้อมูลที่ระบบเก็บเอง)

| ไฟล์ | ที่มา | ใช้ทำอะไร |
|---|---|---|
| `tide_openmeteo_2023-01_05.csv`, `tide_openmeteo_2024-01_05.csv` | Open-Meteo Marine API, ระดับน้ำทะเล (ม., เวลา UTC) ที่ 13.40N 100.55E | fit โมเดลพยากรณ์น้ำดิบสำแล (`collector/samlae_fc.py`) |
| `mwa_ec_conversion_2562.csv` | ตาราง "ความสัมพันธ์ ค่าความนำไฟฟ้า ความเค็ม คลอไรด์ และโซเดียม" จัดทำโดย ฝคภ. กปน. 13 ธ.ค. 2562 | เทียบกับสมการคลอไรด์จากผลแล็บ พ.ค. 2567 และประมาณโซเดียม |
| `mwa_warning_levels.csv` | (1) ระดับการเตือนภัยสถานการณ์ในภาวะวิกฤติภัยแล้ง ปี 2559 (รายงานศูนย์อำนวยการแก้ไขปัญหาวิกฤติการณ์น้ำ) (2) จดหมายข่าว "ประปาชวนรู้" ปีที่ 22 ฉบับที่ 5 มี.ค. 2559 | เทียบเกณฑ์สีของเว็บกับเกณฑ์ที่ กปน. ใช้สื่อสาร |

ข้อสังเกตจากการตรวจ (7 พ.ย. 2569):
- ตาราง ฝคภ. 2562 เป็นสูตรเส้นตรง ไม่ใช่ค่าวัดรายตัวอย่าง: คลอไรด์ = 0.3018 × EC − 92.2, โซเดียม = 0.648 × คลอไรด์ (= 0.1952 × EC − 59.5), ความเค็ม ≈ 0.00054 × EC − 0.046 g/L
- คลอไรด์ 250 มก./ล.: ตาราง 2562 ↔ EC 1,134; ผลแล็บ พ.ค. 2567 (71 ตัวอย่าง, `config/network.json` chloride_fit) ↔ EC 1,210 — สองชุดตรงกันที่ EC ≤ 700 แต่ต่างกันมากขึ้นเมื่อ EC สูง (ปีต่างกัน องค์ประกอบไอออนต่างกัน)
- โซเดียม 200 มก./ล. (WHO) ↔ EC ~1,330 ตามตาราง 2562 (ยังไม่มีผลแล็บโซเดียมยืนยัน)
- ความเค็มต่อ EC ในเอกสาร กปน. ไม่ตรงกัน: ตาราง 2562 → EC 1,200 = 0.60 g/L; ประปาชวนรู้ 2559 → 1,200 = 0.50 g/L (เว็บใช้ 0.000433 × EC → 0.52 g/L)
- ประปาชวนรู้ 2559: น้ำประปาปกติ EC 200–350; เมื่อ EC ถึง 400 กปน. แจ้งโรงงานอุตสาหกรรมบางประเภท (ฟอกย้อม กระจก สี เลนส์) ให้เตรียมระบบ RO; เกณฑ์เฝ้าระวังน้ำดิบ = ความเค็ม 0.25 g/L
