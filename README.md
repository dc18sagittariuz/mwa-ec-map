# แผนที่ความนำไฟฟ้าน้ำประปา (EC) — กรุงเทพฯ นนทบุรี สมุทรปราการ

โครงการส่วนตัว ไม่ใช่ระบบทางการของการประปานครหลวง

ติดตามและคาดการณ์ค่าความนำไฟฟ้า (EC) ของน้ำประปาช่วงน้ำเค็มรุก ระบายสีรายเขต/อำเภอ บน GitHub Pages

## ทำงานอย่างไร

GitHub Actions รัน `collector/run.py` ทุก 30 นาที

1. ดึงข้อมูล
   - น้ำประปา: twqonline.mwa.co.th (TWQMS)
   - น้ำดิบ: rwc.mwa.co.th (สำแล, ไซฟอนรังสิต, แม่น้ำเจ้าพระยาตาม กม.)
   - น้ำจากเขื่อน: กรมชลประทาน SWOC (C.13 ท้ายเขื่อนเจ้าพระยา, C.35 บ้านป้อม)
   - น้ำขึ้นน้ำลง: Open-Meteo Marine (แบบจำลอง)
2. เพิ่มแถวใหม่ลง `data/history/<แหล่ง>/<ปี-เดือน>.csv`
3. คำนวณและเขียน `docs/data/latest.json` ที่หน้าเว็บอ่าน

## การคาดการณ์

**0–48 ชม.: ส่งต่อค่าที่วัดได้ตามเวลาเดินทางของน้ำ**
EC ที่ก๊อกในอีก h ชม. ≈ EC ที่จุดต้นทางเมื่อ (เวลาเดินทาง − h) ชม. ก่อน + ค่าชดเชยของสถานี
เลือกจุดต้นทางที่ใกล้สถานีที่สุดที่ข้อมูลยังครอบคลุม: ทางออกโรงผลิต → ไซฟอนรังสิต → สำแล
ถ้าน้ำที่จะถึงยังไม่ผ่านจุดวัดใด จะแสดงว่า "ยังคาดการณ์ไม่ได้"

**2–3 วัน: ประเมินความเสี่ยง** จากน้ำจืดที่ปล่อยจากเขื่อน ช่วงน้ำเกิด และแนวลิ่มน้ำเค็ม

## ไฟล์สำคัญ

- `config/network.json` สถานีสูบจ่าย → โรงผลิต → แหล่งน้ำดิบ, สัดส่วนพื้นที่เขต/อำเภอที่แต่ละสถานีสูบจ่ายครอบคลุม, เวลาเดินทางของน้ำ (ตารางเทียบพีค ก.พ. 2564) และเกณฑ์สี
  - ไม่มีขอบเขตโซนจ่ายน้ำ (ใช้คำนวณสัดส่วนไว้ล่วงหน้าเท่านั้น)
- `collector/` ตัวดึงข้อมูล (`sources.py`), การเก็บประวัติ (`store.py`), โมเดล (`model.py`)
- `docs/` หน้าเว็บ

## ข้อจำกัด

- เวลาเดินทางของน้ำมาจากข้อมูลปี 2564 จะปรับเมื่อมีข้อมูลหน้าแล้งจริง
- ยังไม่ได้คิดการเจือจางในถังพักน้ำ ค่าพีคจริงอาจต่ำกว่าที่คาด
- เกณฑ์สีเป็นค่าชั่วคราว
